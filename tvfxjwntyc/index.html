Live since 28 Sep

The server now runs this model (v20; the previous version, v19, served the August model). A self-test run on the deployed server gives this model's fingerprint. Deploy only from the handoff_2026-09-28 folder: the repo's own model/ still holds the August checkpoint.

What beta users will notice

  • Extra rows. About 3 rows in 10 have no real strike behind them (491 of 1,722).
  • Head vs body. The most common slip on body punches and head kicks.
  • Elbows read as hooks. The one strike still often read as a different type.
  • Some athletes are harder. Right-when-detected ranges from 42% to 87% across the test videos.

The shipped model trained for 35 epochs with early stopping and reached validation mean F1 0.819.

A later retrain, which also trained on the test videos (28 Sep), was not shipped. On the held-out validation athletes it detected fewer strikes (84.5% → 77.9%), mostly because one athlete's body jabs dropped from 90% to 31% detected. Accuracy when detected rose (74.9% → 78.5%). test.mp4 fell to 7/9. The model above stays in service.
